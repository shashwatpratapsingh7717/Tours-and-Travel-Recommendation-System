# 🌍 Tours and Travel Recommendation System

An AI-powered recommendation engine that suggests the best travel destinations based on user preferences and categories. This project uses **Natural Language Processing (NLP)** to understand user intent and provide personalized suggestions.

---

### 🚀 Features
* **Smart Search:** Recommend cities based on categories like *Adventure, Beaches, Heritage, or Hill Stations*.
* **Semantic Matching:** Uses `Sentence-Transformers` to find the most relevant destinations.
* **Interactive UI:** Clean and responsive web interface built with **Flask**.
* **Data-Driven:** Analyzes city metadata to rank the best matches for the user.

---

### 🛠️ Tech Stack
* **Language:** Python 3.x
* **Framework:** Flask (Backend)
* **Machine Learning:** Sentence-Transformers, Scikit-learn
* **Data Handling:** Pandas, JSON
* **Frontend:** HTML5, CSS3, Jinja2 Templates
